# Mars Survival Map

One astronaut survival map to compare four candidate human landing sites on Mars: **Jezero Crater, Gale Crater, Valles Marineris, and Arcadia Planitia** - on live NASA and USGS data layers, with a crew-safety panel.

Built by **Team NASA Heist** (Sourav Garai) for the **NASA Space Apps Challenge 2026** challenge "Interplanetary Survival Guide: Martian Map" (Kharagpur, virtual).

**Live site:** https://sourav-bwn.github.io/nasa-heist-martian-map/

## What it does

- Interactive Mars map (Leaflet) with three switchable data layers:
  - **Optical base:** Viking MDIM2.1 color mosaic (NASA Mars Trek WMTS, ~232 m/px)
  - **Topography:** MGS MOLA color shaded relief (NASA Mars Trek WMTS, ~463 m/px), with opacity control
  - **Geology:** USGS global geologic map of Mars (Tanaka et al., 2014, SIM 3292) served by USGS Astrogeology, re-projected client-side through a custom Leaflet `GridLayer` so it aligns pixel-for-pixel with the NASA Trek layers, with opacity control
- Four clickable site cards with **only sourced facts** (water/ice evidence, elevation, terrain, open uncertainties) - the map presents evidence; the comparison conclusion belongs to the crew.
- A side-by-side comparison table of the four sites.
- A crew-safety panel: real MSL Curiosity RAD surface radiation measurements (Hassler et al., 2014, *Science*), dust-storm context, and recent solar activity from NASA's DONKI catalog - explicitly framed as solar context, **not** a live Mars radiation meter.

## Data sources

- NASA Mars Trek WMTS (MDIM2.1, MOLA): https://trek.nasa.gov/mars/
- USGS Astrogeology: global geologic map of Mars, Tanaka et al. 2014 (SIM 3292)
- NASA CCMC DONKI space weather catalog: https://ccmc.gsfc.nasa.gov/tools/DONKI/
- MSL RAD measurements: Hassler et al. 2014, Science 343, doi:10.1126/science.1244797
- SWIM shallow-ice mapping (Arcadia): https://swim.psi.edu/ and https://www.nasa.gov/solar-system/nasas-treasure-map-for-water-ice-on-mars/

All datasets are free and public. No API key is required for the map layers; the safety panel uses NASA's DONKI demo endpoint with an honest fallback when rate-limited (a free api.nasa.gov key can be dropped in).

## Run it

It is a static site: open `index.html` or serve the folder (`python3 -m http.server`). No build step, no dependencies beyond the bundled Leaflet 1.9.x.
